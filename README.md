# Prelegal

A platform for drafting common legal agreements.

## Status

**In progress.** The project is under active development and is targeted for
completion by **7 September 2026**.

The repository currently holds this README, the licence and the template
dataset described below. Setup steps, the commands to run the app, and the test
instructions will be documented here as the implementation lands, rather than
published ahead of code that does not exist yet.

Tracking issue: [#1](https://github.com/65kkmsyc8w-ux/Prelegal/issues/1).

## Templates

`templates/` holds the Common Paper standard agreements the system drafts from,
under CC BY 4.0; see [templates/LICENSE.txt](templates/LICENSE.txt).
[catalog.json](catalog.json) lists the name, description, filename and source
repository of each one.
